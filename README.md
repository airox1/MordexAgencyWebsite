# Mordex Agency Website

This is the portfolio and lead-generation website for Mordex Agency. I built it to showcase my work to local businesses and provide a free ROI calculator so they can see how much revenue they're losing with a bad website. 

It's built with React, Vite, and completely custom CSS. 

**Live Website:** [https://airox1.github.io/MordexAgencyWebsite/](https://airox1.github.io/MordexAgencyWebsite/)

## How to run locally
1. `npm install`
2. `npm run dev`
